# Code of Conduct

CTX404 contributors and participants must keep collaboration respectful, constructive and welcoming.

Harassment, discrimination, personal attacks, doxxing, publication of private project data and deliberate disruption are not accepted. Technical disagreement is welcome when focused on evidence and the work.

Maintainers may edit, hide or remove contributions that violate these expectations and may temporarily or permanently restrict participation. Report conduct concerns privately to the repository owner through the contact options on the maintainer's GitHub profile.

This policy applies in repository issues, pull requests, discussions and other project spaces.
